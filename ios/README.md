# Coffee Break — iOS App

SwiftUI (+ SceneKit for the 3D progression map) app. The `.xcodeproj` is
**generated, not committed** — this container can't run Xcode to produce or
validate one, so the project is defined declaratively in `project.yml` via
[XcodeGen](https://github.com/yonaskolb/XcodeGen).

## Generate the Xcode project

```bash
brew install xcodegen   # one-time, on your Mac
cd ios
xcodegen generate
open CoffeeBreak.xcodeproj
```

Re-run `xcodegen generate` any time `project.yml` changes.

## Before you build

- `project.yml` uses a placeholder Bundle ID (`com.yourcompany.coffeebreak`).
  Replace it with the real Bundle ID once it's created in Apple Developer —
  see `../docs/SETUP.md`.
- `CoffeeBreak/Models/AppConfig.swift` points at a placeholder Railway URL.
  Update it once the backend is deployed.
- Sign in with Apple capability is declared via `project.yml`
  (`com.apple.developer.applesignin`); XcodeGen writes the entitlements file
  for you on generate. You'll still need to enable the capability for the
  Bundle ID in Apple Developer, and add the In-App Purchase capability
  yourself in Xcode's Signing & Capabilities tab (not something XcodeGen
  needs to declare).

## Structure

```
CoffeeBreak/
  App/            — app entry point
  Networking/     — backend API client
  Models/         — config, device identity, DTOs
  Resources/
    Assets.xcassets/ — AppIcon + Logo (see below)
    Info.plist / entitlements — generated by XcodeGen
```

## Visual identity (`02-identite-visuelle.md`)

- **Name**: "Coffee Break" — set as `CFBundleDisplayName` in `project.yml`.
- **App icon**: `Resources/Assets.xcassets/AppIcon.appiconset/icon-1024.png`.
  The source asset (`images/icone-application.jpg` at the repo root, kept
  unmodified) is 1206×1288, not square. Per the creator, it was stretched
  (non-uniform scale, not cropped) to exactly 1024×1024 to meet Apple's
  App Store icon requirement — that's the one deliberate exception to "assets
  are never modified," done because Apple's format leaves no other option.
  Uses the Xcode 14+ single-size app icon feature
  (`ASSETCATALOG_COMPILER_INCLUDE_ALL_APPICON_ASSETS`), so this one image is
  all that's needed.
- **Logo**: `Resources/Assets.xcassets/Logo.imageset/logo-coffee-break.jpg`,
  reintegrated unmodified at its original 738×523. Not used on any screen
  yet — screens start with `08-page-accueil.md`.

Original, untouched source images for every spec file are mirrored under
`/images` at the repo root.

## Game assets (`03-assets-de-jeu.md`)

- `Resources/Assets.xcassets/GameElements/` — the 6 matchable elements
  (cupcake, donut, tartelette, croissant, part de gâteau, bretzel), each
  isolated on a transparent background.
- `Resources/Assets.xcassets/Boosts/` — the 5 boost visuals (café latte,
  café à emporter, matcha latte, canette de soda, jus d'orange), also
  isolated with transparent backgrounds.
- `Resources/Assets.xcassets/Currency/coin-cafe.imageset/` — the coin,
  embedded exactly as provided (the only one of the three source images
  marked `VALIDEE` rather than `brouillon`, so it wasn't touched).
- `CoffeeBreak/Models/GameElement.swift`, `Boost.swift`, `Currency.swift` —
  enums mapping each asset to its imageset name, for later screens/mechanics
  to reference.

**Note on the source files**: the current sprites are extracted from
`images/elements-final.jpg` and `images/boosts-final.jpg` — final composite
images (6, resp. 5, items on a solid pink backdrop) provided by the creator
to replace the initial extraction from the original draft sheets
(`elements-a-matcher-brouillon.jpeg`, `boosts-brouillon.jpeg`, still kept in
`/images` for reference). Each item was cropped and isolated from the pink
background; pixel content of every item was left untouched.

Feature screens aren't built yet — those start with `08-page-accueil.md`
onward, per the numbered spec order. Match-3 mechanics (`05-mecaniques-de-jeu.md`)
and boost powers (`06-pouvoirs-des-bonus.md`) aren't implemented yet either
— only the visual assets and naming are in place so far.
