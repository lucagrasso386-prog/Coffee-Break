# Coffee Break — iOS App

SwiftUI (+ SceneKit for the 3D progression map) app. The `.xcodeproj` is
**generated, not committed** — this container can't run Xcode to produce or
validate one, so the project is defined declaratively in `project.yml` via
[XcodeGen](https://github.com/yonaskolb/XcodeGen).

## Generate the Xcode project

```bash
brew install xcodegen   # one-time, on your Mac
cd ios
xcodegen generate
open CoffeeBreak.xcodeproj
```

Re-run `xcodegen generate` any time `project.yml` changes.

## Before you build

- `project.yml` uses a placeholder Bundle ID (`com.yourcompany.coffeebreak`).
  Replace it with the real Bundle ID once it's created in Apple Developer —
  see `../docs/SETUP.md`.
- `CoffeeBreak/Models/AppConfig.swift` points at a placeholder Railway URL.
  Update it once the backend is deployed.
- Sign in with Apple capability is declared via `project.yml`
  (`com.apple.developer.applesignin`); XcodeGen writes the entitlements file
  for you on generate. You'll still need to enable the capability for the
  Bundle ID in Apple Developer, and add the In-App Purchase capability
  yourself in Xcode's Signing & Capabilities tab (not something XcodeGen
  needs to declare).

## Structure

```
CoffeeBreak/
  App/            — app entry point
  Networking/     — backend API client
  Models/         — config, device identity, DTOs
  Resources/      — Info.plist / entitlements (generated by XcodeGen)
```

Feature screens aren't built yet — those start with `08-page-accueil.md`
onward, per the numbered spec order.
